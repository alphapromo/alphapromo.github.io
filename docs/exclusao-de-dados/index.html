Como excluir seus dados da Alpha Promo

Para pedir a exclusão dos dados ligados a você (nome de usuário e identificadores de comentários respondidos), envie uma mensagem direta para @alphapromo.ofertas no Instagram ou um e-mail para alphapromo.ofertas@gmail.com com o assunto "Excluir meus dados" e o seu nome de usuário do Instagram.

Os dados são apagados em até 30 dias e você recebe uma confirmação pelo mesmo canal.

Você também pode remover o acesso a qualquer momento em Instagram → Configurações → Apps e sites.
